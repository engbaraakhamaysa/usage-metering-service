# Routes

TanStack Start uses file-based routing. The six page routes are account,
plans, users, consumption, records, and translation. The index route redirects
to account. Route components delegate to the existing `src/pages/` components.

`__root.tsx` supplies the app shell, providers, styles, and nested outlet.
Preserve the outlet and providers. `src/routeTree.gen.ts` is generated by the
TanStack plugin; do not edit it manually.
